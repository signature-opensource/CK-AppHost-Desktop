# CK.IO.AppHost.Desktop

The commands of a desktop application (CK.AppHost.DesktopNgApp handles them): `IGetDesktopInfoQCommand` (whether the
application has its window and a text log), `IOpenLastLogCommand` (closes the current text log and opens it) and
`IOpenLogFolderCommand` (opens the folder of the text logs) and `IPickFolderCommand` (the folder dialog of the system).

See the [README](https://github.com/signature-opensource/CK-AppHost-Desktop/blob/stable/CK.IO.AppHost.Desktop/README.md).
